PocketPixel is a global four-colour pixel filter for Unity 6 URP 3D using the Universal Renderer.

**[Try the live demo](https://minmax.ch/demos/pocketpixel/pocketpixel-demo.php)** · [English guide](https://github.com/MinmaxCH/PocketPixel/blob/main/README.md) · [Deutsche Anleitung](https://github.com/MinmaxCH/PocketPixel/blob/main/README.de.md)

- Five palettes, editable colours, pixel size, dithering and depth/normal outlines.
- Automatic Universal Renderer setup and per-user English/German Inspector selection.
- Editable C# and shader source, previews and documentation included.
- Developed with Unity 6000.4.0f1 and URP 17.4.0. Built-in, HDRP and the URP 2D Renderer are not supported.

Download **PocketPixel-1.0.1.unitypackage** for installation. Drag it into Unity's Project window, confirm **Import**, then add **Assets/PocketPixel/Pixel Filter.prefab** to your scene.

**PocketPixel-1.0.1-komplett.zip** contains the complete source, previews and documentation. **SHA256SUMS** provides the checksums for both downloads.

The live demo is hosted separately on minmax.ch. Its scene, player controller, menu, Web build and Joomla integration are not included in the filter downloads.

The existing custom attribution licence applies unchanged; see the included licence for the required credit and complete terms. The separate demo checks and remaining validation gaps are documented in [VALIDATION.md](https://github.com/MinmaxCH/PocketPixel/blob/main/VALIDATION.md).
